### Catalog Automation

* Impact FTP credentials are stored in `~/.netrc` with `chmod 600`,
  allowing `ftp products.impact.com` to authenticate automatically.
* Catalog metadata is available through `catalogs_info_file.xml`,
  including each retailer's remote catalog path and `lastUpdated`
  timestamp.
* `update-onp.sh` checks the remote catalog timestamps against the
  local files.
* If unchanged, it does nothing.
* If changed, it downloads the new catalog, archives/replaces the
  old data, and triggers the Lisp database reload for that retailer.
* `systemd` runs the updater on a schedule via `update-onp.timer`
  (see the OnCalendar setting in that file).

Setup:

* `mv update-onp.service update-onp.timer ~/.config/systemd/user/`
* `systemctl --user daemon-reload`
* `systemctl --user enable --now update-onp.timer`
* `sudo loginctl enable-linger YOUR_USERNAME` lets the user-level
  timer continue running after logout.
* `systemctl --user list-timers` verifies the schedule.
* `systemctl --user start update-onp.service` runs the job
  immediately for testing.
* `journalctl --user -u update-onp.service -f` follows its output --
  Ctrl-C to stop following once the run finishes (it doesn't exit
  the follow automatically).
